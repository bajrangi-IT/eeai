# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of EleEdu AI seriously. If you believe you have found a security vulnerability, please report it to us by opening a private issue or contacting the maintainers directly.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send a fix within 14 days.
